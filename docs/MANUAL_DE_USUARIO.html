Manual de uso de DEM Workflows

Guía completa para preparar insumos, construir flujos, calcular relieve e hidrología, interpretar resultados y repetir el trabajo con trazabilidad.

01 · Cómo utilizar este manual

DEM Workflows es una aplicación de escritorio para construir cadenas de procesamiento de modelos digitales de elevación, inspeccionar sus resultados y repetirlas sobre nuevos insumos.

El trabajo se organiza en un proyecto. Dentro de él, el flujo describe las operaciones, y cada nodo indica una herramienta con sus entradas y parámetros. Las capas visibles en el mapa pueden ser fuentes, resultados temporales o productos exportados.

Primera vez

Empieza por instalación, proyecto y recorrido de pendiente geográfica. Después consulta las fichas de herramientas.

Trabajo repetitivo

Revisa flujos reutilizables, variables, lotes y políticas de exportación. Conserva el proyecto para recuperar la procedencia.

Si aparece un error

Localiza el primer nodo en rojo y consulta la tabla de diagnóstico. Los nodos bloqueados suelen ser una consecuencia de ese fallo.

El índice permanece disponible en pantallas grandes; en el móvil se abre con Índice. La búsqueda encuentra capítulos y fichas. Los ejemplos de código tienen botón Copiar. Imprimir / PDF utiliza la impresión del navegador; no envía datos a ningún servicio.

Alcance real. Incluye las mejoras de pendiente en coordenadas geográficas, carpeta de salida, intervalos de reclasificación, recortes con margen métrico, histograma automático, ventanas separadas, selección múltiple, retiro de capas con deshacer y visualización asíncrona con detalle según el encuadre. Las operaciones hidrológicas y las demás derivadas métricas conservan sus requisitos particulares.

02 · Instalación y apertura

En el equipo donde ya está instalado

  1. Abre la carpeta procesamiento-dem.
  2. Ejecuta Iniciar_DEM.cmd. El lanzador usa el entorno .venv del proyecto.
  3. Si había una instancia abierta antes de actualizar el código, guarda el proyecto, ciérrala y abre el lanzador de nuevo.

Para ver mensajes de arranque, inicia desde PowerShell en la carpeta del repositorio:

& '.\.venv\Scripts\python.exe' -m dem_tool gui

En otro equipo Windows

Se necesita Python 3.11 o superior. El proyecto dispone de un instalador de entorno, no de un ejecutable autónomo firmado. Indica la ruta correcta del Python que deseas usar:

.\Instalar.ps1 -Python 'C:\ruta\python.exe'
.\Iniciar_DEM.cmd

El instalador crea .venv y ejecuta una instalación editable con dependencias y pruebas. Para reproducir las versiones verificadas, instala requirements-lock.txt antes de instalar el paquete sin resolver dependencias:

& '.\.venv\Scripts\python.exe' -m pip install -r requirements-lock.txt
& '.\.venv\Scripts\python.exe' -m pip install --no-deps -e .

No es necesario instalar R, QGIS, SAGA ni GRASS. El entorno no reemplaza las instalaciones de Python de ArcGIS. NumPy se mantiene por debajo de 2.3 por compatibilidad con el motor hidrológico incluido.

Comprobación inicial

Al abrir verás la marca DEM / WORKFLOWS, botones para cargar DEM y vectores, un mapa vacío y el editor de flujo. Cargar una capa permite verla; para generar un resultado también debes añadir y ejecutar uno o más procesos.

03 · Proyectos, entradas y guardado

Crear, guardar y recuperar

  1. Archivo → Nuevo proyecto: elige una carpeta sin otro project.json. El proyecto inicial también puede crearse automáticamente en workspace/Proyecto_fecha_hora.
  2. Archivo → Guardar proyecto: conserva el flujo, las referencias a archivos, la unidad vertical, la carpeta de salida y las capas con su simbología.
  3. Archivo → Abrir proyecto: selecciona el archivo project.json, no un archivo de flujo exportado.

Los insumos originales se referencian por ruta: no se copian automáticamente al proyecto. Si mueves un DEM o un shapefile, sus referencias pueden quedar rotas. Las rutas dentro del proyecto se guardan relativas; las externas permanecen absolutas. Al trasladar un shapefile conserva también sus archivos asociados, especialmente SHX, DBF y PRJ.

Cargar raster y vector

+ DEM admite en el selector TIF, TIFF, IMG y ASC. La cadena DEM requiere normalmente una banda. Para trabajar con un archivo multibanda utiliza Extraer banda antes de las operaciones de relieve. Visualizar otra banda en Simbología solo cambia el mapa.

+ Vector / máscara admite GPKG, SHP y GeoJSON. La capa debe tener CRS y geometrías. Si todas las geometrías son Point se registra como $point; las demás se registran como $mask. Una máscara de recorte normalmente debe ser poligonal.

Las variables de entrada

VariableSignificado

Unidad vertical

El selector superior Unidad Z del DEM admite metros (m), pies internacionales (ft) y pies estadounidenses (us-ft). No se deduce del CRS horizontal. En los nodos que lo permiten, inherit utiliza la información de la capa o la unidad del proyecto. Verifica esta unidad antes de calcular pendientes o volúmenes.

Asignar EPSG:4326 no convierte elevaciones a grados: el CRS describe la posición horizontal. Una altura de 4 000 m sigue siendo una altura métrica aunque X/Y estén en longitud/latitud.

Encuadre y navegación

Llenar vista ocupa el panel con una escala proporcional; puede ocultar bordes de una imagen muy alargada. Ver toda la extensión y Extensión completa muestran toda la extensión con margen. Zoom a capa centra la capa seleccionada. La rueda acerca y aleja alrededor del cursor; la mano desplaza y el rectángulo selecciona un área de zoom.

Para identificar un valor, selecciona un raster, desactiva la mano o el zoom rectangular y haz clic sobre el mapa. La barra de estado muestra fila, columna y valor de la banda; fuera del dato se indica NoData o Fuera de extensión. La identificación lee el píxel original, aunque el mapa tenga una vista reducida.

Quitar varias capas en una sola acción

  1. Haz clic en una capa del árbol. Mantén Ctrl para sumar o retirar elementos de la selección; usa Mayús para seleccionar un rango.
  2. Para seleccionar todas, da foco al árbol y pulsa Ctrl+A. Las cabeceras ENTRADAS, TEMPORALES y RESULTADOS no cuentan como capas.
  3. Pulsa Quitar (N), la tecla Supr o el botón derecho → Quitar capas seleccionadas. El contador indica cuántas se retirarán.
  4. Para recuperarlas usa Deshacer, botón derecho → Deshacer retiro de capas o Ctrl+Z con el foco en el árbol.

La operación retira capas del mapa y del listado guardado del proyecto. Conserva los archivos en disco y las variables de entrada del workflow: un proceso que use $dem o $mask seguirá encontrando ese insumo. Quitar una capa no elimina su nodo de procesamiento. Para cambiar los insumos de una receta usa Workflow → Entradas y variables.

Deshacer restaura orden, nombre, estilo y estado visible de cada capa retirada. Se conservan las últimas diez acciones durante la sesión; al cambiar de proyecto o reiniciar la aplicación ese historial se pierde. Si falla el guardado del proyecto, el retiro o la restauración no se aplica. Una nueva ejecución puede volver a incorporar sus resultados aunque los hayas retirado del mapa.

El menú contextual también incluye Mostrar seleccionadas y Ocultar seleccionadas. Ambas acciones afectan a toda la selección y actualizan la vista una sola vez. La selección y los grupos contraídos se conservan al refrescar el árbol. Seleccionar una fila y activar su casilla son operaciones distintas.

Visibilidad y orden

Las casillas del árbol controlan la visibilidad. Los rasters se dibujan según el orden de capas y los vectores se superponen como contornos/líneas/puntos. Una capa visible posterior puede tapar otra. Oculta el DEM cuando quieras inspeccionar claramente un producto de pendiente. La opacidad puede ayudar a comparar, pero no cambia ningún valor de cálculo.

Histograma y estadísticas automáticas

Al cargar el mapa sin selección explícita aparece automáticamente el histograma del raster superior. Seleccionar otra capa muestra sus propiedades; un refresco del mapa conserva esa elección mientras la capa siga visible. Si eliges un vector o una tabla, el panel muestra sus propiedades y oculta el histograma raster para evitar confundir datos. Si ocultas todas las capas, el panel queda sin raster. Cambiar selección, banda o intervalos prepara la información en segundo plano; aparece un aviso mientras se calcula.

El número de intervalos va de 2 a 1 000. Cambiarlo modifica la distribución visual, no los datos. Se ofrecen mínimo, máximo, media, mediana, desviación estándar poblacional y percentiles 2, 25, 50, 75 y 98. Los valores NoData no entran en esos estadísticos.

Tres escalas distintas. El mapa usa una vista reducida de la ventana visible: hasta 800, 1 400 o 2 200 píxeles por lado según Rápida, Equilibrada o Detalle, y un presupuesto compartido de ocho millones de píxeles si hay muchos rasters visibles. Las estadísticas usan el raster completo hasta un millón de píxeles y una muestra regular aproximada por encima de ese umbral. Los algoritmos calculan sobre su entrada original. El histograma corresponde a la banda, no al rectángulo visible después del zoom.

Al acercar o desplazar, primero se mueve la vista disponible. Tras una pausa breve en la navegación se prepara el nuevo encuadre. Mientras aparece Preparando vista…, puedes seguir trabajando: únicamente la solicitud más reciente se presenta al terminar. En archivos grandes la lectura inicial todavía puede tardar; trabajar en segundo plano evita que esa espera paralice los controles.

El detalle se obtiene leyendo la ventana de datos que corresponde al encuadre. No se inventan nuevos valores cuando se alcanza la resolución original. La calidad elegida afecta al mapa, no a los cálculos, los archivos de salida o la identificación de un píxel. Al cambiar de tamaño el panel se mantienen el centro y el rango vertical del zoom, adaptando el ancho.

Los colores automáticos se basan en una muestra global de la banda, estable durante el desplazamiento: al acercarse no se recalcula el contraste solo con ese sector. Las geometrías vectoriales se reproyectan y simplifican únicamente para dibujarlas; los originales se conservan. Para comparar límites con precisión, acerca la vista y usa Detalle.

La aplicación reutiliza las imágenes, las muestras estadísticas y los nodos del grafo. El grafo conserva selección y zoom mientras cambian los estados de procesamiento. Para reducir aún más el trabajo gráfico, oculta capas que no necesites y utiliza Rápida. Los temporales en disco y la caché de cálculos son independientes de estas vistas.

06 · Construir y editar un flujo

Un flujo es un grafo dirigido sin ciclos. Cada nodo consume fuentes externas o salidas de otros nodos. El orden lógico lo determinan esas conexiones, aunque los nodos cambien de posición en la lista.

Añadir un proceso

  1. Abre el grupo apropiado: Preprocesamiento, Relieve, Hidrología, Álgebra raster, Vectores o Cuencas.
  2. Elige una herramienta. Si había un nodo seleccionado, su salida se propone como entrada inicial; revisa todos los puertos antes de guardar.
  3. Escribe un nombre reconocible; aparecerá en las capas y en los archivos exportados.
  4. Selecciona cada entrada. Un campo dem espera raster; mask, extent o point esperan vector cuando la herramienta lo indica.
  5. Ajusta parámetros, estado activo, política de exportación, tipo de salida y NoData.
  6. Guarda. Para lanzar una prueba del nodo y sus antecesores, utiliza Vista previa.

Grafo y tabla

Grafo de dependencias muestra cajas y conexiones. Doble clic abre un nodo. Nodos y conexiones presenta el mismo flujo en una tabla. Las conexiones se editan con los selectores de entrada del formulario, no arrastrando cables sobre el dibujo.

Duplicar crea un nodo independiente con nueva identidad; conserva parámetros y referencias de entrada. Eliminar exige desconectar primero los nodos que dependan del seleccionado. Activar alterna su estado. Desactivar un nodo bloquea la rama que lo necesita: no conecta automáticamente su entrada con sus salidas.

Las flechas ↑ y ↓ reorganizan la lista. No pueden forzar que un nodo se calcule antes que una dependencia. Un ciclo se rechaza. Un formulario puede guardarse sin completar conexiones, pero el flujo no se ejecutará hasta que sus puertos requeridos estén resueltos.

Ventana independiente

Pulsa Abrir flujo en otra ventana para ampliar el editor. Puedes maximizarlo, usar zoom y Ajustar grafo. Volver a acoplar o cerrar esa ventana lo devuelve al mapa con sus mismos nodos y estados.

Vista previa

Ejecuta el nodo solicitado y todas sus dependencias, sin exportaciones automáticas. Procesa la entrada completa del nodo, no la vista del mapa. Puede utilizar resultados de caché. Los parámetros se guardan al aceptar el formulario.

07 · Recorrido completo: pendiente geográfica

Este recorrido sirve para obtener clases de pendiente y polígonos a partir de un DEM en EPSG:4326 y una máscara del área de interés.

  1. Crea un proyecto y carga el DEM con + DEM. Selecciona la unidad Z correcta.
  2. Carga el polígono mediante + Vector / máscara.
  3. Añade Recortar por máscara. Conecta dem → $dem y mask → $mask. Deja el buffer en 0 para usar el límite original o indica un margen en metros.
  4. Si es necesario reducir ruido, añade Suavizado / filtros conectado al recorte. Revisa el efecto de kernel e iteraciones: modifican el relieve y, por tanto, la pendiente.
  5. Añade Pendiente conectado al recorte o al suavizado. Usa Horn para el ejemplo, salida en grados y Float32 o Float64.
  6. Añade Reclasificar conectado a Pendiente. Define límites compatibles con grados, selecciona los intervalos y usa UInt8 si los códigos son 1–4.
  7. Añade Poligonizar clases conectado al raster reclasificado. Deja conectividad 4 salvo que necesites unión diagonal.
  8. Añade Disolver por atributo conectado al vector; utiliza el campo value.
  9. Elige una carpeta de salida y exportación Detallado para conservar todos los productos, o Finales para conservar solo la salida terminal.
  10. Ejecuta, revisa los estados, activa la capa de pendiente y consulta su histograma.

Cómo se trata la geografía

Pendiente conserva la extensión, resolución, alineación y CRS del raster. Las elevaciones se convierten a metros según su unidad. Las distancias horizontales se calculan sobre el elipsoide del CRS en cada fila; no se usa un factor constante de metros por grado. El método funciona también en CRS proyectados con píxeles rectangulares.

El enfoque se inspira en terra::terrain; aquí la implementación usa Python, SciPy y PyProj. No requiere R ni afirma coincidencia exacta con sus resultados. Otras herramientas métricas, como curvatura e hidrología, requieren todavía un CRS proyectado.

Verificación real disponible. El recorte de Yanacancha utilizado en la prueba tiene 1171 × 1381 píxeles; se calcularon 865 241 pendientes válidas y la cadena hasta disolución terminó sin errores. Es evidencia de ejecución y conservación espacial, no validación de campo.

08 · Recortes, CRS y márgenes métricos

Recorte por máscara

El DEM y el vector pueden tener CRS distintos. El motor transforma la máscara al CRS del raster y conserva la cuadrícula de este. buffer_m = 0 usa la geometría original. Valores positivos amplían y valores negativos contraen la máscara; se rechaza un buffer que la elimine por completo.

Si el DEM es proyectado, el margen se convierte a las unidades lineales de su CRS. Si es geográfico, el buffer utiliza una proyección azimutal equidistante local y luego regresa al CRS del DEM. La operación métrica local no admite áreas de más de 30° por eje cuando se solicita un margen.

Recorte por extensión

  1. Conecta un vector al puerto opcional extent, o pulsa Seleccionar capa vectorial.
  2. Como alternativa, introduce [xmin,ymin,xmax,ymax]. Usa el orden X/Y: oeste, sur, este, norte en geográficas.
  3. Si las coordenadas escritas están en otro CRS, indícalo en CRS de la extensión. Vacío significa el CRS del DEM.
  4. Indica Ampliar extensión, en metros por lado. Debe ser un número no negativo.

Si se conectó un vector, su extensión tiene prioridad sobre los límites escritos. Si no se proporcionan límites ni vector, se usa la extensión del DEM. El recorte se ajusta a píxeles completos y a la intersección con el raster existente: ampliar la extensión no inventa terreno fuera del DEM.

En las reglas 0–5 y 5–15 no pueden estar ambos intervalos cerrados en el valor 5. Sí pueden dejarlo fuera de ambas clases, pero ese valor quedará como NoData o se conservará según Valores no cubiertos. Los límites deben ser finitos y desde menor que hasta.

Puedes añadir/quitar filas e importar/exportar CSV. Los intervalos contienen comas, por lo que el CSV debe entrecomillarlos:

from,to,value,interval
0,5,1,"[a,b)"
5,15,2,"[a,b)"
15,30,3,"[a,b)"
30,90,4,"[a,b]"

Los archivos antiguos con include_to siguen siendo admitidos. false equivale a [a,b) y true a [a,b]. En Valores no cubiertos, nodata descarta lo no clasificado; keep mantiene el valor original y puede producir valores fraccionarios incompatibles con una salida entera.

Calculadora raster

Conecta A y, si hace falta, B. Las cuadrículas deben coincidir. Las funciones disponibles son min, max, mean, median, std, percentile, where, log, sqrt y abs. Los estadísticos ignoran NoData. No se admiten código Python libre, archivos, importaciones, atributos ni índices.

A - mean(A)
(A - mean(A)) / std(A)
(A - min(A)) / (max(A) - min(A))
where(A > percentile(A, 90), 1, 0)
where((A > 10) & (B < 30), A, B)

Escribe una sola expresión, no todas las líneas del ejemplo. Usa & y | con condiciones entre paréntesis. Los valores indefinidos se convierten en NoData. En una expresión que usa A y B se conserva la intersección de sus píxeles válidos, incluso dentro de where.

La media y los percentiles utilizados en la calculadora se obtienen de la entrada completa del cálculo, no de la muestra del histograma ni de la extensión visible del mapa.

10 · Hidrología y morfometría paso a paso

Preparación

Trabaja con un DEM de una banda en CRS proyectado y una unidad Z conocida. Recorta un área suficientemente amplia para representar la contribución aguas arriba: un recorte administrativo puede cortar una cuenca. NoData representa ausencia de información; no lo conviertas automáticamente en elevación cero.

Cadena inicial D8

  1. Selecciona Plantillas → Hidrología D8. La plantilla tiene cuatro nodos.
  2. Rellenar depresiones elimina depresiones con pysheds. Puede resolver planos y guardar la diferencia de relleno. Profundidad máxima 0 significa sin límite; un límite excedido detiene el nodo.
  3. Dirección de flujo D8 crea direcciones según ocho vecinos. Revisa las advertencias de planos o depresiones sin resolver.

Ajustar punto y delimitar cuenca

  1. Añade Ajustar punto de salida y conecta la acumulación.
  2. Escribe X/Y en el CRS del raster. El umbral identifica celdas candidatas de drenaje; Tolerancia máxima limita la distancia de ajuste en metros.
  3. Conecta su punto de salida y la dirección D8 a Delimitar cuenca. Alternativamente puedes usar un vector externo con exactamente un Point, ya colocado correctamente.
  4. El nodo devuelve un raster binario de cuenca y registra el punto de salida.

Ajustar punto de salida utiliza coordenadas X/Y del formulario. No tiene un puerto de vector para leer automáticamente el punto cargado; un vector externo sí puede conectarse directamente a Delimitar cuenca.

Órdenes y morfometría

Añade Strahler con dirección y drenajes si deseas una salida independiente de orden. Morfometría necesita cinco entradas alineadas: DEM, cuenca, dirección, drenajes y orden. Utiliza el DEM que representa las alturas que deseas medir; el relleno hidrológico puede modificar elevaciones.

La salida principal de Morfometría es CSV; sus artefactos son XLSX y GeoPackage. Incluye área/perímetro, elevaciones, relieve, pendiente media, longitud de cuenca, longitud y pendiente del cauce principal, longitud total de drenaje, número de segmentos, densidad, frecuencia, orden máximo e índices de forma.

Qué reutiliza la caché

Las entradas, parámetros, tipo de salida, unidad vertical, código y bibliotecas participan en la clave del cálculo. Si coinciden y los archivos guardados siguen íntegros, se reutiliza el resultado. Cambiar un parámetro recalcula ese nodo y sus descendientes; cambiar únicamente la carpeta de salida permite copiar resultados ya calculados al nuevo destino.

La caché no es un respaldo de insumos. Modificar archivos originales, versiones del programa o dependencias puede invalidarla. La simbología no altera el cálculo.

Al cerrar

La aplicación guarda el proyecto y puede preguntar si se eliminan los temporales. La opción predeterminada es conservarlos. Si los eliminas, las exportaciones permanecen, pero perderás esa caché y pueden dejar de estar disponibles dependencias hidrológicas temporales hasta ejecutar de nuevo.

Lectura del registro

El mensaje final indica resultados, reutilizados, exportados, errores y ruta del log. El archivo JSONL conserva eventos de los nodos con fecha, parámetros, entradas, duración y errores. Al solicitar ayuda, comparte el primer error, el nombre de la herramienta, CRS, unidad Z y dimensiones del DEM; no hace falta compartir datos sensibles para empezar el diagnóstico.

16 · Límites, buenas prácticas y glosario

Límites comprobados en el código

  • El procesamiento de muchos algoritmos carga arrays completos; no hay motor general por teselas ni hidrología distribuida.
  • read_raster limita inicialmente a 25 millones de celdas. Los recortes usan rutas de lectura distintas y tampoco garantizan memoria constante para cualquier área.
  • La reproyección rechaza destinos de más de 100 millones de celdas. Una salida permitida por ese límite podría superar el límite de lectura de un nodo posterior.
  • No hay edición vectorial general, ajuste automático de todas las cuadrículas ni selección de múltiples salidas de cuenca dentro de un único nodo.
  • Los motores disponibles son los incluidos en Python; no hay selección funcional de Whitebox, GRASS, SAGA o R.
  • Geomorphons, openness, sky-view factor, HAND, TWI, SPI, STI, LS, D∞ y MFD no forman parte de esta implementación.

Antes de interpretar

Comprueba resolución, unidad vertical, NoData y recorte. Documenta cualquier suavizado o relleno. Mantén iguales umbrales y definiciones si comparas zonas. Una clase de pendiente describe inclinación; por sí sola no estima probabilidad de deslizamiento, peligro, vulnerabilidad o riesgo.

19 · Delimitación y vectorización de microcuencas

Abre Plantillas → Microcuencas por tramos D8. Esta receta adapta el script 01_delinea_microcuencas.py al motor, las variables, la caché y las exportaciones de la aplicación. Produce áreas de aporte local de cada tramo; no necesita puntos de salida.

Configurar y ejecutar

  1. Elige el DEM de entrada, monobanda y con CRS conocido. Puede ser el DEM ya cargado o uno distinto.
  2. Revisa el CRS proyectado en metros. El asistente sugiere el CRS métrico del DEM o un UTM según el centro; la sugerencia no reemplaza revisar su idoneidad para toda la zona. En Cajamarca puede corresponder EPSG:32717; en el ejemplo Yanacancha se usa EPSG:32718.
  3. Define resolución, umbral contribuyente y área mínima final. Los valores iniciales son 60 m, 0,45 km² y 0,10 km².
  4. Activa AOI si necesitas una zona de interés; elige un vector poligonal con CRS y el margen del dominio, inicialmente 5 000 m. El CRS del vector puede ser distinto del DEM. Sin AOI se procesa todo el raster.

Parámetros y significado

La contribución mínima se expresa en área física: 125 × 60 × 60 / 1 000 000 = 0,45 km². Al cambiar resolución se conserva ese umbral en km², no el número de celdas. Un umbral menor suele producir una red más densa y más unidades; no obliga a que cada microcuenca tenga exactamente ese tamaño. La resolución afecta el enrutamiento y los límites; remuestrear a 60 m no crea información adicional.

Con AOI hay once nodos: primero se recorta una envolvente ampliada y al final se recorta el vector al límite exacto. Sin AOI hay diez nodos. El margen permite incluir terreno exterior, pero 5 km no garantizan contener todos los aportes aguas arriba. Evita enmascarar el relieve al límite administrativo antes de la hidrología. Un DEM demasiado grande debe recortarse antes de las operaciones que leen el raster completo.

Qué se entrega

El GeoPackage contiene la capa microcuencas con MB_ID, LINK y AREA_KM2. MB_ID es único dentro de esa salida. LINK conserva el ID del tramo de origen y puede repetirse si una geometría se divide en varias partes. AREA_KM2 corresponde a la geometría final después del recorte. El último nodo permite cambiar el prefijo MB- y el filtro mínimo.

Las áreas de aporte son locales y disjuntas: una celda pertenece al primer tramo que alcanza. El tramo inferior no contiene de nuevo las áreas ya asignadas a otros tramos superiores. Para una cuenca completa desde un punto usa Delimitar cuenca. Al recortar al AOI, las geometrías resultantes pueden ser solo partes de una microcuenca hidrológica.

El filtro de área se aplica después de separar partes; los polígonos pequeños se descartan, no se fusionan con vecinos. Las celdas sin cauce alcanzable quedan NoData. Por eso no debe esperarse cobertura completa del AOI, ni igualdad exacta de resultados con el script original.

Diferencias de la adaptación

La aplicación sustituye los componentes conexos de ocho vecinos por conectividad D8 dirigida: evita unir canales paralelos que se tocan. La confluencia inicia el tramo aguas abajo, en vez de convertirse en un tramo aislado. Detecta ciclos y usa orden topológico para propagar IDs; respeta las máscaras NoData y no fuerza receptores fuera del raster hacia el borde mediante np.clip.
